# n8n-nodes-human-in-the-loop

This is a node for [n8n](https://n8n.io/) that enables Human-in-the-Loop (HITL) workflows. It allows you to pause automated workflows to get human input or approval before continuing.

## Features

- Pause workflow execution until human input is received
- Configurable approval/rejection options
- Optional comments field for feedback
- Webhook-based notification system
- Customizable timeout settings

## Installation

### In n8n:
1. Go to Settings > Community Nodes
2. Select "Install"
3. Enter `n8n-nodes-human-in-the-loop` in "Enter npm package name"
4. Click "Install"

### Manual Installation:
1. Visit the [n8n-nodes-human-in-the-loop GitHub Releases page](https://github.com/n8n-io/n8n-nodes-human-in-the-loop/releases)
